1. Establish connection with the instance in the folder with the ssh-key. Go to instance, click on ID, click Connect, copy the command from "Example" at the bottom


2. Install compose:
sudo wget -q https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m) -O /usr/local/bin/docker-compose

chmod +x /usr/local/bin/docker-compose


3. Install docker:
sudo yum install docker


4. Install git:
sudo yum install git


5. Change IPs in the files (Server/server.js - line 6, Client/App.jsx - line 131) to the IP of the machine
6. Push changes to the git
7. Pull the changes on the machine or clone from https
8. Start compose:
sudo docker-compose up --build
9. Works with HTTP and port 8080
